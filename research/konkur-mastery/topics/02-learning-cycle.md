# چرخه یادگیری (شواهدمحور)

## اصل طلایی
**بازیابی فعال + فاصله‌گذاری** از بازخوانی و هایلایت مؤثرتر است.

### یافته‌های کلیدی پژوهش
- Practice testing و distributed practice در مرور Dunlosky و همکاران (۲۰۱۳) «کاربرد بالا» گرفتند؛ هایلایت/بازخوانی کاربرد پایین
- Roediger & Karpicke: بازیابی فعال نگهداری را به‌شدت بهتر از بازخوانی می‌کند
- Cepeda و همکاران: فاصله‌گذاری تقریباً همیشه از انباشت یک‌جا بهتر است
- ترکیب بازیابی + فاصله از هرکدام جدا قوی‌تر است
- تلاش برای یادآوری حتی اگر ناموفق باشد، یادگیری بعدی را بهتر می‌کند

## چرخه پیشنهادی برای هر مبحث
1. **نقشه ۳ دقیقه‌ای** — از حفظ بنویس چی باید بلد باشی
2. **Pretest** — چند تست/سؤال قبل از درسنامه کامل
3. **Sparring نقطه‌ای** — فقط روی غلط‌ها و حفره‌ها از جزوه/ویدیو
4. **Retest** — تست جدید
5. **کدگذاری برای مرور** — کارت/فرمول/ایده در غلط‌نامه
6. **بازبینی فاصله‌دار** — فردا / ۳ روز / ۷ روز / قبل آزمون

## توهم تسلط
آشنا بودن متن ≠ بلد بودن سر جلسه.  
معیار: بتوانی بدون نگاه حل کنی / توضیح بدهی / در زمان محدود بزنی.

## برای فراموشی بعد از گپ (وضعیت یازدهم وحشی)
- بازخوانی کل کتاب ممنوع به‌عنوان استراتژی اصلی
- هر فصل: pretest → sparring → retest
- روزانه یک خرده‌مبحث زنده کن، نه سه فصل مرده
