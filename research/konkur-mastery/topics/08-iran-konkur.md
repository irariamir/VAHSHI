# بافت کنکور ایران (کاربردی برای وحشی)

## واقعیت سیستم
- چهارگزینه‌ای + نمره منفی
- آزمون آزمایشی (ماز، قلم‌چی، ...) برای بودجه‌بندی و محک
- کلاس آنلاین/حضوری باید به برنامه شخصی قفل شود نه برعکس

## تبدیل نهایی تشریحی → تستی
- نهایی مفهوم را «آشنا» می‌کند؛ کنکور «بازیابی زیر زمان» می‌خواهد
- پل: هر مبحث نهایی‌خوانده = بسته تست آموزشی + زمان‌دار

## هماهنگی دو آزمون (ماز + قلم‌چی)
- یک ستون اصلی بودجه نزدیک‌ترین آزمون سخت
- دومی برای محک و بانک
- هفته بدون آزمون رسمی: آزمونک معلم = رسمی فرض شود

## منابع
- یک درسنامه اصلی (جزوه استاد)
- یک بانک تست اصلی (باکس/هم‌تراز)
- از کوه منبع بپرهیز
