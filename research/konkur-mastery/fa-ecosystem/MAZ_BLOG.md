# ماز (biomaze) — یافته‌های کلیدی

## تست‌زنی مضربی
- به‌جای زدن همه تست‌های فصل: الگوی عددی (زوج/فرد، مضرب ۲/۳/۵)
- فایده: صرفه‌جویی زمان، جلوگیری از خستگی، پوشش گسترده‌تر، مناسب جمع‌بندی
- اجرا: انتخاب الگو → حجم پارت → تحلیل (آموزشی یکی‌یکی؛ سنجشی بعد بسته) → مرور هایلایت‌ها
- ترکیب با کلاس/آزمون: بعد کلاس همان مبحث؛ بعد کارنامه مضرب روی ضعف

## روش‌های رتبه‌برتر (ماز)
1. تصادفی کوچک برای تنوع تیپ
2. مرحله‌ای روی ضعف
3. زمان‌دار (حدود ۳۰–۵۰ تست در ۳۰–۴۵ دقیقه)
4. مرور تحلیلی با کارنامه
5. ترکیب تست کوتاه و بلند
6. روتین شبانه نیم‌ساعته برای محاسباتی (شیمی)

## انواع تست
- آموزشی: یادگیری؛ بدون اصرار زمان/درصد
- زمان‌دار: شبیه‌سازی و سرعت
- جمع‌بندی: بازیابی سریع
- تحلیل غلط = تکمیل یادگیری

## اشتباهات خطرناک
- تست بدون تحلیل
- فقط سخت‌ها و فراموشی آسان
- نزدن زمان‌دار

## وسواس مطالعاتی
علائم: چندباره‌خوانی، برگشت به کل فصل بعد غلط، کمبود وقت، چندمنبعی، خلاصه حجیم‌تر از کتاب  
درمان:
- درسنامه کوتاه → فوری تست آموزشی
- برنامه حجمی-زمانی
- منبع متناسب سطح
- بعد غلط فقط همان تکه ۲–۳ دقیقه
- تسلط با تست نه ده دور درسنامه

## سرعت مطالعه
- نشسته پشت میز
- خالی‌کردن ذهن قبل شروع
- قانون پارکینسون: حجم مشخص در زمان مشخص
- پرهیز بلندخوانی
- راهنمای انگشت روی خط
- دور اول روزنامه‌وار بعد عمق
- نمودار درختی
- مرور با تست فاصله‌دار
- حذف موبایل

## مرور
- آزمون = مرور فعال
- تدریس/فاینمن
- بالارد: مطالعه → استراحت مطلق ۱۵ دقیقه → مرور سریع
- آخر هفته + پلکانی روزانه/هفتگی/ماهانه

## فیزیک
- مفهوم قبل فرمول؛ کتاب درسی مهم
- عمده زمان تست
- تیپ‌بندی مکتوب
- اول تمارین کتاب
- پاسخ‌نامه تله: اول جزوه بعد پاسخ
- علامت غلط/زمان‌بر/نکته‌دار
- دقت واحد و صورت سؤال

## شیمی (اولویت وحشی)
- سه دسته: حفظی / مفهومی / مسئله (حدود ۳۰٪ محاسبات)
- حفظی: کتاب + قید + تست خرد + مرور مداوم
- مفهومی: درک + ۲۰–۳۰ تست بعد هر تکه
- مسئله: روتین روزانه سرعت
- شیمی روزانه در برنامه
- خلاصه: حاشیه + جدول + برگه مباحث تست‌خیز
- منبع اول کتاب درسی؛ مسائل ترجیحا منبع جدا
