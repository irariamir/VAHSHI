# قوانین ایجنت از اکوسیستم فارسی

1. اگر وحشی گفت بلدم ولی تست نمی‌شود → درسنامه کم، تست آموزشی/پوششی زیاد.
2. اگر وسواس/کمال دید → حجمی-زمانی + ممنوع برگشت به کل فصل.
3. شیمی سفید → روزانه + سه لایه حفظی/مفهومی/محاسبه؛ کتاب درسی حفظی واجب.
4. فیزیک قوی → تیپ‌برگ و زمان‌دار؛ درسنامه جدید کمتر.
5. دو آزمون → راهبردی بیرونی + دفتر شخصی درونی.
6. هفته انعطاف → فقط سهم، نه ساعت اجباری.
7. همیشه تحلیل > تعداد خام.
