# Progress Tracker

## متریک‌ها
- ساعت مطالعه روزانه/هفتگی
- تعداد تست هر درس (آموزشی/تسلطی/زمان‌دار)
- تراز آزمون (نمودار)
- درصد مرور انجام شده

## Workflow
1. هر شب از وحشی بپرس: امروز چند ساعت خوندی؟
2. ثبت در state.db
3. اگر 3 روز افت کرد → هشدار مهربان + کاهش حجم موقت
4. اگر رشد کرد → تشویق + افزایش 10% چالشی

## بصری‌سازی
- نمودار میله‌ای هفتگی
- هیت‌مپ مطالعه
- پیشنهاد تولید تصویر برای انگیزه
