# Pomodoro Blocks

## Defaults
- تمرکز عمیق: 50/10 یا 25/5 بسته به تحمل
- بعد از ۴ بلوک: استراحت بلند ۲۰–۳۰م
- موبایل خارج دسترس در بلوک

## Day template
1. گرم‌کردن ۱۰م (مرور سبک)
2. ۲–۳ بلوک سخت‌ترین درس (صبح)
3. ۱–۲ بلوک تست
4. ۱ بلوک مرور/غلط‌نامه
5. جمع‌بندی شب ۱۰م

## Adjust
- زیر ۳ ساعت مفید/روز → 25/5
- بالای ۶ ساعت → 50/10 + قیلوله کوتاه اختیاری
