# Priority Engine

## Score (0-5 each)
- ضریب / اهمیت رشته
- شدت ضعف
- نزدیکی آزمون/جمع‌بندی
- انرژی فعلی وحشی (واقعی)
- وابستگی پیش‌نیاز

## Procedure
1. لیست ۳–۷ کاندید
2. امتیاز بده (ذهنی اما شفاف)
3. Top 1–3 را برای امروز قفل کن
4. بقیه backlog

## Phrase
«امروز فقط اینا امتیاز کشتن دارن؛ بقیه نویزه.»
