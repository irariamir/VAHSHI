# Review Cycle

## Cadence (عملی کنکوری)
- D0: یادگیری + تست آموزشی
- D1: مرور سریع خلاصه/فلش
- D3: تست مخلوط مبحث
- D7: آزمونک
- D21/ماه: مرور جمع‌بندی

## Tools
- غلط‌نامه مقدس‌تر از تست جدید بی‌هدف
- علامت‌گذاری: سفید / مشکوک / غلط

## Rule
اگر حجم مرور از آموزش بیشتر شد و وحشی ضعیف مفهومی است، اول مفهوم را درست کن.
