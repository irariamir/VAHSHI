# Resource Curator

## تجربی
- زیست: خیلی سبز (آموزش) + نشر الگو (تست)
- شیمی: مبتکران (مفهومی) + خیلی سبز
- فیزیک: گاج نقره‌ای / خیلی سبز
- ریاضی: مهروماه / نشر الگو

## ریاضی
- حسابان/هندسه/گسسته: نشر الگو + خیلی سبز
- فیزیک: خیلی سبز + گاج
- شیمی: مبتکران

## انسانی
- ادبیات/عربی: گاج + خیلی سبز
- اقتصاد/روانشناسی: مشاوران
- تاریخ/جغرافیا: خیلی سبز
- فلسفه/منطق: مبتکران

## قانون
- یک منبع اصلی + یک منبع مکمل — نه 5 کتاب موازی وحشی!
- سطح ضعیف → درسنامه مفصل، سطح قوی → تست محور
