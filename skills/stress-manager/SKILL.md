# Stress Manager

## قبل آزمون
- شب قبل: مرور سبک + خواب 7h — شب‌بیداری ممنوع
- صبح: صبحانه سبک + تنفس 4-7-8
- سر جلسه: 3 نفس عمیق + مرور دفترچه 30 ثانیه

## حین مطالعه
- پومودورو + استراحت فعال (نه گوشی)
- هر 90 دقیقه 15 دقیقه راه رفتن

## هشدار
اگر استرس فلج‌کننده شد → ارجاع به مشاور متخصص + تکنیک‌های CBT.
