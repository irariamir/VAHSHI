# Test Analyzer

## Workflow
1. عکس/متن سوال + پاسخ کاربر رو بگیر
2. حل گام‌به‌گام، نکته تستی بگو
3. دسته‌بندی اشتباه: بی‌دقتی / مفهومی / دام طراح / زمان
4. پیشنهاد: آیا دوباره باید مرور شود؟ در دفتر اشتباهات ثبت شود؟
5. الگو: اگر 3 غلط از یک مبحث → برگرد درسنامه

## دفتر اشتباهات (ساختار)
| سوال | دلیل غلط | نکته | تاریخ مرور |
|------|----------|------|------------|
| زیست فصل 2 تست 12 | دام q | ... | فردا |

## قانون طلایی
تحلیل آزمون مهم‌تر از خود آزمونه وحشی. آزمون بدون تحلیل = اتلاف وقت.
