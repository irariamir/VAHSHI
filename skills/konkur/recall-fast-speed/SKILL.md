# Recall Fast + Test Speed (ریاضی)

## When to Use
- یازدهم/مباحث فراموش‌شده باید سریع برگردند
- سرعت و دقت تست پایین آمده بعد از نهایی/تعطیلی

## Core idea
بازیابی = **بازیابی فعال + تست** نه بازخوانی رمان‌وار کتاب.
سرعت = تشخیص الگو + قلم روان + مدیریت زمان، نه عجله کور.

## Protocol A — بازیابی ۴۸ ساعته یک فصل (۹۰–۱۲۰م)
1. **۳ دقیقه نقشه:** سرفصل‌های فصل را از روی جزوه/فهرست بنویس (بدون کتاب باز برای جواب).
2. **۱۲ دقیقه pretest:** ۱۰–۱۵ تست از همان فصل (ماز باکس / جزوه / قلم‌چی قدیم). غلط‌ها را فقط علامت بزن.
3. **۲۵–۳۵ دقیقه sparring:** فقط برای غلط‌ها و تیپ‌های تکراری، از جزوه استاد همان تکه را بخوان — خط به خط کل فصل ممنوع.
4. **۳۰–۴۰ دقیقه retest:** ۱۵–۲۰ تست جدید همان تیپ‌ها، زمان‌دار.
5. **۱۰ دقیقه کارت:** حداکثر ۷ کارت: فرمول / دام / ایده کلیدی.

خروجی: فصل «زنده برای تست» نه «خوانده‌شده».

## Protocol B — روزانه یازدهم (۴۵–۷۵م) تا ۲ شهریور
- هر روز **یک** تیپ/خرده مبحث پایه، نه سه فصل.
- نسبت: ۲۰٪ درسنامه نقطه‌ای / ۸۰٪ تست+تحلیل.
- چرخه: D0 pretest → sparring → retest → فردا ۵ سوال از دیروز.

## Protocol C — سرعت تست (۳ بار در هفته، ۴۰–۵۰م)
1. بسته ۲۰ سوال هم‌درس (نه مخلوط سخت اول کار).
2. دور ۱: فقط سوالات <۹۰ثانیه مطمئن (۱۲–۱۵م).
3. دور ۲: متوسط‌ها (۱۵م).
4. دور ۳: سخت/رها (۵–۸م) — یادگیری نه اصرار.
5. تحلیل فقط غلط + شک‌دار (۱۵م). برچسب: مفهوم / محاسبه / صورت / کندی بی‌دلیل.

### متریک سرعت
- ثبت کن: سوال/دقیقه در بسته‌های ۲۰تایی.
- هدف ۲ هفته: +۱۵–۲۵٪ سرعت با حفظ دقت؛ اگر دقت ریخت، سرعت را برگردان.

## Protocol D — غلط‌نامه قدرتی (هر روز ۱۵–۲۰م)
ستون‌ها: تاریخ | درس | تیپ | علت | ایده نجات | تاریخ بازآزمون
بازآزمون: ۲۴س / ۷۲س / ۷روز

## Protocol E — اتصال به کلاس ماز
قبل کلاس (۱۵–۲۰م): pretest از مبحث جلسه.
بعد کلاس (۳۰–۴۵م): ۱۰–۱۵ تست همان مبحث از باکس/جزوه.
فردا: ۵ سوال تأخیری.

## Anti-patterns
- خواندن کل یازدهم از صفحه ۱
- تست بدون تحلیل
- همزمانی کد/ربات وسط بلوک سرعت
- مقایسه تراز قبل از ۲ هفته ثبات
