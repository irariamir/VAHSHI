# Resource Picker

## Principles
- یک منبع اصلی + یک منبع تست کافی است؛ کوه کتاب = فرار
- سطح ضعیف: آموزش پله‌ای + تست آموزشی
- متوسط: درسنامه جمع‌وجور + تست زمان‌دار
- قوی: آزمون و تحلیل بیشتر از درسنامه جدید

## Common FA stacks (راهنما نه تبلیغ)
- خیلی سبز / نشر الگو / گاج / مبتکران / IQ / آبی قلم‌چی — بر اساس درس و سطح
- قبل از خرید جدید: از منبع فعلی چند فصل را تمام کرده باشد

## Output
- منبع اصلی پیشنهادی
- منبع تست
- چه چیزی را کنار بگذارد
