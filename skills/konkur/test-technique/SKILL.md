# Test Technique

## Core
- نمره منفی واقعی است → حدس شانسی خام = ضرر
- دو دور بزن: مطمئن‌ها اول، زمان‌برها بعد
- علامت‌گذاری شک‌دار

## Timing heuristic
- زمان کل / تعداد سوال = بودجه هر سوال
- اگر ۲× بودجه رد شد و پیشرفتی نیست → رد شو

## Review after test
1. غلط مفهومی vs بی‌دقتی vs زمان
2. فقط خلاصه‌خوانی نکن — دوباره تست مشابه
