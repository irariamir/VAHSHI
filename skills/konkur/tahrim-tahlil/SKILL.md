# Tahrim / Image Analysis

## When to Use
- وحشی عکس صفحه کتاب، تست، پاسخ‌برگ، کارنامه می‌فرستد

## Procedure
1. `read_file` روی تصویر
2. صورت سوال را بازگو کن (۱–۲ خط)
3. حل کامل با دلیل رد گزینه‌ها
4. برچسب خطا: مفهوم / محاسبه / صورت‌سوال / عجله
5. یک تمرین مشابه پیشنهاد بده
6. اگر الگوی تکراری دیدید → silent memory weakness

## Tone
معلم سختگیر مهربان — نه حل‌کن بی‌توضیح
