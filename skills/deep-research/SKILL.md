# Deep Research

## Workflow
1. web_search با query دقیق (depth 2-3)
2. web_extract برای صفحات مهم
3. ترکیب + اعتبارسنجی چند منبع
4. پاسخ با citation [id](url)
5. هشدار اگر تناقض بود

## قوانین
- هر ادعای کنکوری باید با sanjesh.org چک شود
- اگر منبع رسمی نبود بگو «مطمئن نیستم وحشی»
- خلاصه کوتاه + لینک منبع
