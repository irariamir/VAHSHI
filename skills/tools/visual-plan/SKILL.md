# Visual Plan

## When
وحشی می‌خواهد برنامه را به‌صورت عکس یا اینفوگرافیک ببیند

## Procedure
1. داده برنامه را از master-planner داشته باش
2. `generate_image` با پرامپت تمیز، فارسی در تصویر اگر لازم، خوانا، تاریک/نئون VAHSHI
3. ذخیره در `/home/user/.vahshi/dashboard/exports/` یا `/home/user/`
4. `present_file` برای نمایش

## Design
- کم‌متن، بلوک رنگی روزها
- عنوان: برنامه وحشی — هفته X
