# Work Audit

## When to Use
- وحشی می‌گوید «این هفته این کارا رو کردم»
- پیگیری بعد از دادن برنامه

## Ask (کوتاه)
1. چند ساعت واقعی؟
2. کدام بخش برنامه انجام شد / نشد؟
3. میانگین درصد یا تعداد تست؟
4. بزرگ‌ترین مانع؟

## Procedure
1. مقایسه با برنامه فعال
2. علت ریشه‌ای: برنامه سنگین؟ تعلل؟ ضعف منبع؟ انرژی؟
3. اصلاح برنامه (کم کردن حجم > شعار بیشتر بخون)
4. silent memory: مانع تکراری و تنظیم جدید
5. log session چکیده

## Rule
هرگز سرزنش تحقیرآمیز. اقتدار + راه‌حل.
