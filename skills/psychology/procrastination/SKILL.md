# Procrastination

## Protocol
1. علت: ترس از سختی / کمال‌گرایی / خستگی / محیط
2. قانون ۲ دقیقه: فقط میز + تایمر + صفحه اول
3. شروع با آسان‌ترین تکه از سخت‌ترین درس
4. کاهش اصطکاک: منبع باز از دیشب، گوشی دور
5. اگر ۳ روز تکرار شد → کوچک کردن بلوک‌ها نه سرزنش

## Phrase
«نمی‌خواد کامل باشه؛ فقط باید شروع بشه.»
