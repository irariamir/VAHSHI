# Burnout Reset

## Signs
نفرت از کتاب، خواب‌آلودگی مزمن، افت لذت، مطالعه با گناه

## Protocol
1. تشخیص: خستگی حاد vs فرسودگی چندهفته‌ای
2. ۷۲ساعت ریست ساخت‌یافته (خواب، نور، حرکت، قطع مقایسه مجازی)
3. بازگشت پلکانی: ۵۰٪ حجم قبلی برای ۳–۵ روز
4. حذف کار کم‌بازده از برنامه
5. یک لذت غیرکنکوری مجاز و زمان‌بندی‌شده

## Rule
«استراحت بی‌ساختار» اغلب به اسکرول تبدیل می‌شود — ریست باید طراحی شود.
