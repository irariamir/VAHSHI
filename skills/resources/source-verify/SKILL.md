# Source Verify

## When
تاریخ ثبت‌نام، ضرایب، تأثیر معدل، سهمیه، حذفیات

## Procedure
1. `web_search` با سال جاری (تاریخ سیستم را جدی بگیر)
2. اولویت: sanjesh.org > رسانه‌های معتبر نقل‌کننده دفترچه
3. اگر قطعی نیستی: صریحاً بگو و از وحشی بخواه دفترچه را چک کند
4. عدد مشکوک را در MEMORY به‌عنوان «verified» علامت نزن

## Never
- ساختن تاریخ یا ضریب از حافظه مدل
