# Book Stack FA

## Roles
- درسنامه کامل
- درسنامه جمع‌وجور
- تست پلکانی
- تست دشوار
- آزمون جامع
- جمع‌بندی نهایی

## Advice engine
1. نقش مورد نیاز را مشخص کن
2. یک گزینه اصلی بده + جایگزین
3. هشدار: سلیقه معلمان فرق دارد — ۲ هفته تست کن و عوض کن اگر نمی‌چسبد

## Note
نام ناشران رایج: خیلی سبز، گاج، مبتکران، الگو، مهر و ماه، قلم‌چی، گزینه‌دو...
