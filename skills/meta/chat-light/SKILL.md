# Chat Light

## Hard rules every message
1. First line: Tehran time (short)
2. No code blocks unless user says «کد بده»
3. No file paths, JSON, shell, stack traces
4. No long research dumps — store in GitHub, reply short
5. Prefer tables/short bullets
6. Details live in repo, not chat
