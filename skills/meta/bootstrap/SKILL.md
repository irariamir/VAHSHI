# Bootstrap

## When to Use
- ابتدای کار مهم / وقتی وحشی می‌پرسد «چی یادت مونده؟»
- بعد از وقفه طولانی

## Procedure
1. اجرا کن: `python /home/user/.vahshi/agent.py boot`
2. وضعیت: `python /home/user/.vahshi/agent.py status`
3. اگر `intake.complete == false` و درخواست برنامه داشت → skill `intake-evaluation`
4. SOUL را نقض نکن؛ USER/MEMORY را به‌عنوان حقیقت جلسه بگیر
5. skills/INDEX را برای intent matching در ذهن داشته باش

## Output
- رفتار هم‌راستا با حافظه
- بدون اعلام «دارم فایل می‌خونم» مگر درخواست صریح
