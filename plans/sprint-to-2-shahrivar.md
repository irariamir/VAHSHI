# Sprint تا ۲ شهریور — وحشی
**امروز مرجع کاربر:** ~۱۸ مرداد | **آزمون:** ۲ شهریور ماز  
**مسیر:** جمع‌بندی یازدهم (نه دهم عمیق) | **ساعت درس:** ۸ مفید | **باشگاه:** عصر ~۲س

---

## ۱) هدف آزمون ۲ شهریور (واقع‌بین + تهاجمی)
- شرکت کامل دفترچه اجباری روی **لاین یازدهم**
- هدف حسی: «دست گرم + شناخت دقیق ضعف» نه معجزه رتبه ۱ در یک آزمون
- تراز/درصد: برگشت به باند قبلی قلم‌چی و بالاتر از حالت rust — عدد دقیق بعد از کارنامه ۱۶ مرداد اگر داری تنظیم می‌شود
- دفترچه ۳ (۱۲): فقط دروس/صفحاتی که حداقل یک‌بار pretest شده

---

## ۲) بودجه اجباری — چک‌لیست تسلط

### ریاضی‌پایه / حسابان متصل
- [ ] تعیین علامت  
- [ ] معادلات گویا  
- [ ] معادلات گنگ  
- [ ] تست زمان‌دار مخلوط ۲۰تایی × حداقل ۳ دور تا آزمون  

### هندسه ۲
- [ ] دایره فصل ۱ (۹–۳۰) — تعریف/زاویه/وتر/مماسی‌ها طبق جزوه واعظین  
- [ ] بسته ۱۰–۱۵ تستی × ۳  

### آمار و احتمال
- [ ] فصل ۱ مبانی (۱–۳۴)  
- [ ] ۳۰ تست + خلاصه نمادها  

### فیزیک ۲
- [ ] الکتریسته ساکن ۱–۴۴  
- [ ] فرمول‌برگ + ۲۰ تست مفهومی + ۲۰ محاسباتی  

### شیمی ۲
- [ ] فصل ۱ تا آلکن‌ها ۱–۴۰  
- [ ] حفظ جدول/آرایش + استوکیومتری ابتدایی اگر داخل بازه است + تست

## ۳) اسکلت هفتگی (با کلاس‌های تو)

### شنبه — روز کلاس‌محور (هندسه+فیزیک)
- صبح (قبل کلاس): ۳–۳.۵س  
  - ۱.۵س ریاضی تعیین‌علامت/معادلات (pretest+sparring)  
  - ۱.۵س شیمی یا آمار (چرخشی)
- ۱۵:۳۰–۱۸:۱۵ هندسه واعظین + ۳۰–۴۵م تست بعد  
- ۱۸:۳۰–۲۱:۴۵ فیزیک شجاعی + اگر جان ماند ۲۰م فرمول‌برگ  
- باشگاه: اگر کلاس تا ~۲۲ طول کشید → gym کوتاه‌تر یا بعد شام سبک / جابجا با روز کم‌کلاس  
- شب: غلط‌نامه ۱۵م + مدیتیشن

### یکشنبه — بازیابی عمیق + حسابان شب
- صبح تا عصر: ۴.۵–۵.۵س پایه (ریاضی + فیزیک ساکن + هندسه دایره)  
- ۱۵:۱۵ عربی فقط اگر عمومی فعال شد؛ وگرنه همان بلوک = آمار/شیمی  
- ۲۰:۱۵–۲۱:۳۰ حسابان کرمی + بعد ۳۰م تست  
- باشگاه عصر قبل حسابان ترجیحاً  
- side-code: فقط اگر ۸س درس OK

### دوشنبه — شیمی‌محور
- صبح: ریاضی‌پایه + هندسه دایره  
- ۱۵:۱۵ فارسی اگر فعال  
- ۱۶:۴۵–۲۰ شیمی هادیان‌فرد + بعد تست همان مبحث  
- شب: سرعت‌تست فیزیک یا ریاضی ۴۰م  
- باشگاه: صبح زود یا بعد ۲۰ اگر بدن می‌کشد

### سه‌شنبه — گسسته + فیزیک شب
- صبح: بودجه ۲ شهریور (آمار یا شیمی عقب‌افتاده)  
- ۱۵:۱۵ دین اگر فعال  
- ۱۶:۴۵–۲۰ گسسته انصاری — برای آزمون ۲ شهر، گسستهٔ ۱۲ اختیاری است؛ **اگر خسته‌ای اولویت با بودجه اجباری یازدهم** بعد کلاس  
- ۲۰–۲۱:۳۰ فیزیک شجاعی  
- باشگاه: پنجره تنگ — کوتاه یا جابجا

### چهارشنبه — حسابان سنگین + شیمی شب
- ۱۵:۱۵–۱۹/۲۰ حسابان (کرمی/عزیزی) → بعدش تست تابع/پایه مرتبط با تعیین علامت  
- ۲۰:۱۵–۲۱:۳۰ شیمی  
- صبح: فیزیک الکتریسته + غلط‌نامه هفته  
- باشگاه: قبل کلاس‌ها یا روز بعد جبران

### پنجشنبه — شبیه‌ساز / بانک
- صبح: نیم‌آزمون یا بسته‌های بودجه‌ای پشت‌سرهم (ریاضی۲۰ + هندسه۱۰ + آمار۱۰)  
- ظهر: فیزیک۲۰ + شیمی۲۰ (زمان‌دار)  
- عصر: **فقط تحلیل** + باشگاه  
- شب: سبک

### جمعه — تثبیت + ریکاوری فعال
- بازآزمون غلط‌ها  
- یک دور فرمول‌برگ همه دروس بودجه  
- اگر انرژی: پیش‌خوانی خیلی سبک دفترچه۳ (تابع۱–۵ یا الکترو۱۲ نه)  
- خواب بیشتر

## ۵) تقسیم حجم پیشنهادی تا ۲ شهریور (۸س/روز)
تقریبی از زمان مفید خارج کلاس:
- ۳۵٪ ریاضی‌پایه (تعیین علامت/گویا/گنگ)  
- ۲۰٪ فیزیک الکتریسته  
- ۱۵٪ شیمی فصل ۱  
- ۱۵٪ هندسه دایره  
- ۱۰٪ آمار فصل ۱  
- ۵٪ سرعت‌تست/تکنیک + پیش‌۱۲ فقط اضافه

کلاس‌ها جداگانه روی این سوار می‌شوند (بعدکلاس = همان درس).

## ۶) روز آزمون ۲ شهریور
- شب قبل: خواب؛ نه خواندن جدید  
- صبح: گرم‌کن ۲۰م فرمول  
- سر جلسه: دفترچه اجباری اول — ریاضی پایه با دقت؛ فیزیک/شیمی مسیر یازدهم  
- دفترچه ۳ فقط اگر زمان و انرژی ماند  
- بعد آزمون همان روز: استراحت کوتاه + شب فقط لیست ضعف برای ۱۳ شهریور
