# سیستم طراحی آریامیر (از ariamir.gt.tc)

## هویت بصری
- دارک‌فرست، RTL فارسی
- حس: سوپابیس/پروداکت زنده — نه پوستر شلوغ، نه UI مصنوعی شلخته
- فونت فارسی سایت: Kalameh + IRANYekan
- فونت لاتین: Manrope / JetBrains Mono برای کد و عدد انگلیسی
- برای رندر تصویر در محیط فعلی: Vazirmatn تا Kalameh-TTF موجود شود (وزن‌ها مشابه)

## الگوی کامپوننت سایت
- کارت تیره با border ظریف (`es-card`)
- دکمه سبز (`es-btn-g`) روی CTA سبز تیره
- تیتر درشت فارسی، ساب‌تایتل fg2/fg3
- فاصله‌گذاری هوا‌دار (نه فشرده AI)
- یک لهجه سبز؛ بدون گرادیان رنگارنگ و بدون نئون زیاد
- گوشه‌های نرم، خطوط موئی سبز فقط برای تأکید

## قوانین ضد-AI-look
1. حداکثر ۱ رنگ تأکید
2. بدون سایه سنگین رنگارنگ
3. بدون ستاره/کهکشان شلوغ مگر برند بخواهد خیلی ملایم
4. گرید منظم و gutter ثابت
5. متن هرگز روی هم نرود؛ ستون‌بندی واقعی
6. لوگو فقط یک‌بار و با فضای تنفس
7. عدد و برچسب در ستون ثابت

## خروجی‌های برنامه روزانه
- قالب ترجیحی: لیست کارت + متریک ۳تایی + فوتر قانون
- استایل مرجع ذهنی: Linear restraint + Ariamir tokens
